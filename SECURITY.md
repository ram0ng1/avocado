# Security Policy

## Supported versions

Only the latest release of `ramon/avocado` receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report it privately through GitHub: open the repository's **Security** tab and click
**Report a vulnerability** (<https://github.com/ram0ng1/avocado/security/advisories/new>).

Include the affected version, the steps to reproduce and, if possible, the impact you
expect. You will get an answer within a few days; once a fix is released the advisory
is published with credit to the reporter (unless you prefer to stay anonymous).
